# Paper qualitative views

These 21 images are the matched captures selected for the paper. `views.json`
records their checksums, labels and highlighted regions. The report reconstructs
the panel layout from these images on full runs.

The original viewer did not save its camera matrices. These panels are reference
captures, not new renderings of the reconstructed meshes. Short diagnostics omit
them. The measured quality and runtime tables use the new campaign outputs.
